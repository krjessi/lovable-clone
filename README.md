#Lovable Clone Application

A Spring Boot based social connection platform inspired by Lovable.

## Tech Stack
- Java 24
- Spring Boot
- Spring Security (JWT Authentication)
- Hibernate / JPA
- PostgeSQL
- REST APIs

### Other Tools
- Maven
- Postman
- Git & GitHub

## Features
- User Registration & Login (JWT Authentication)
- Profile Management (Creation & Editing)
- Send & Accept Connection Requests
- Secure REST APIs
- Role-based Authorization
- Exception Handling & global Error Response

## Architecture
- Controller Layer -> Service Layer -> Repository Layer -> Database

Includes:
- DTO Mapping
- Global Exception Handling
- JWT Authentication Filter
- Role-Based Authorization

## Database Design
Tables:
- Users
- Profiles
- Connection
- Messages
- Roles

## How to Run Locally
1. Clone repository
2. Navigate to project
3. Configure environment variables
4. Run application

## Environment variables Required
- DB_USERNAME
- DB_PASSWORD
- JWT_SECRET
